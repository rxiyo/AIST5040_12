# 从不完整粉末 XRD 推断晶格参数

固定金红石型 TiO₂ 的元素与分数坐标，用有噪声的模拟粉末 XRD 谱反演两个晶格参数。项目比较物理网格拟合、MLP 点回归、条件高斯混合模型（MDN）、同一生成候选池加物理重排。物理网格同时提供密集网格和等候选预算的稀疏网格。

## 本机复跑

当前工作区已将 pymatgen 和它的依赖安装在项目的 `.deps` 目录。本机可以从项目目录运行：

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) '.deps')
python run_benchmark.py
```

小组成员首次安装时，建议使用各自的虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_benchmark.py
```

先验证代码链路时，可以用小规模运行。使用不同输出目录可保留正式结果：

```powershell
python run_benchmark.py --train 30 --validation 10 --test 5 --grid-side 11 --budget-side 3 --iterations 8 --output outputs/smoke
```

扩展实验使用种子 42、43、44。每个种子配对比较常规峰宽和仅测试谱峰宽增加的情形。逐个运行可以避免在线计时受并发干扰。

```powershell
foreach ($seed in @(42, 43, 44)) {
    python run_benchmark.py --seed $seed --test-peak-sigma 0.12 --output "outputs/study/matched/seed-$seed"
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
    python run_benchmark.py --seed $seed --test-peak-sigma 0.20 --output "outputs/study/broadened/seed-$seed"
    if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }
}
python analyze_study.py
```

## 实验设计

- 正演代码在 `physics.py`。使用 Cu Kα 波长、pymatgen 计算的反射峰位和强度，以及标准差为 0.12° 的高斯峰形。固定原子分数坐标，独立均匀采样两个晶格参数。
- 每个底谱分别得到完整扫描（20–70°）、以 (110) 为主的低信息窗口（24–33°）、包含 (101) 等反射的等宽对照窗口（33–42°）。每个窗口按自身最大峰归一化，再加标准差为 0.01 的高斯噪声。同一晶胞各窗口共享角度坐标上的噪声实现。未观测数据有独立掩码。
- 默认划分为 1,800 个训练、240 个验证、160 个测试晶胞。每个晶胞的三个窗口都留在同一划分。模型的特征归一化只用训练数据，MDN 的权重检查点由验证集负对数似然选择。
- 两种学习方法共享降采样谱和掩码特征。MLP 返回一个点。MDN 训练三个对角高斯分量，推断时从限制在搜索区间内的混合分布抽 36 组参数。物理重排复用同一批提案，按已观测点的均方残差排序。基于物理评分的列表在数值并列时优先选择靠近参数先验中心的候选。
- 密集网格默认评估 1,681 个点，等预算网格评估 36 个点。两种网格都预先缓存正演谱。等候选预算比较使用相同的误差评分，但网格预计算与生成候选实时正演的成本不同，需同时参考在线时间和离线建库时间。
- Top-1 / Top-5 命中要求两个参数各自在真值 0.02 Å 内。保留的候选之间用 0.01 Å 的最大坐标差阈值去重，最多返回 5 个。点回归只报告 Top-1。CSV 里的谱残差用于事后诊断，点回归和未重排的生成候选在推断阶段没有物理评分。

当前模型用同一个衍射模拟器生成数据和评分。实验范围为单相、已知原型、固定峰宽的模拟谱，适合分析窗口信息量与参数歧义。向实验谱推广需要单独验证。

峰宽失配实验将测试谱的高斯峰宽从 0.12° 增加到 0.20°。同一随机种子在两种峰宽下共享训练、验证和测试晶胞，也共享噪声的随机实现。训练谱、模板与候选评分仍用 0.12°。跨种子标准差描述重复实验的变动。在线时间由机器负载影响。

多样性消融复用各样本原来的 36 个 MDN 提案，保留物理重排的 Top-1，在谱残差接近的候选中优先选择晶格参数彼此相隔较远的点。不足五个时按物理拟合顺序补齐。阈值允许候选的残差平方和相对最佳候选增加最多六倍名义噪声方差。阈值用于比较排序策略，适用范围由这组模拟实验决定。

## 首轮结果

随机种子 42，160 个独立测试晶胞，每个晶胞在三个窗口下分别评估。

| 观测条件 | 密集网格 a MAE (Å) | 密集网格 c MAE (Å) | 等预算网格 Top-5 | MDN Top-5 | MDN + 物理重排 Top-5 |
|---|---:|---:|---:|---:|---:|
| 完整扫描 | 0.00123 | 0.00110 | 100% | 100% | 100% |
| 低信息窗口 | 0.00124 | 0.02891 | 96.88% | 96.25% | 91.88% |
| 等宽对照窗口 | 0.00233 | 0.00078 | 99.38% | 100% | 100% |

低信息窗口把密集网格的 c 误差放大约 26 倍，而等宽对照窗口仍可较准确地恢复 c。低信息窗口中，物理重排将平均可见谱 MSE 从 0.000190 降到 0.000101，同时把 Top-5 从 96.25% 降到 91.88%。这组结果展示了谱拟合与参数覆盖的差别。等预算网格的 Top-5 仍很强，缓存网格的在线时间也低于逐候选重新正演。以上是单种子、同模拟器的初步结果。

## 扩展实验结果

三个种子各有 160 个独立测试晶胞。表格中 MAE 以 Å 为单位，命中率是三个种子的平均值。

| 测试峰宽 | 密集网格 c MAE · 完整谱 | 密集网格 c MAE · 低信息 | 密集网格 c MAE · 等宽对照 | 低信息窗口 MDN / 物理重排 / 重排加多样性 Top-5 |
|---|---:|---:|---:|---:|
| 0.12° | 0.00108 | 0.02955 | 0.00078 | 95.00% / 92.29% / 94.38% |
| 0.20° | 0.00151 | 0.02955 | 0.00201 | 93.75% / 91.46% / 91.88% |

1. 低信息窗口下，密集网格对 c 的点估计误差与始终输出先验区间中心相同。等宽对照仍能恢复 c，说明这组窗口差别主要来自保留了哪些反射。
2. 匹配峰宽下，低信息窗口的 36 个 MDN 提案有 99.79% 的概率至少包含一组合格参数。只按物理残差选出的五组命中率为 92.29%，多样性策略恢复到 94.38%。峰加宽后，多样性改善缩小到 0.42 个百分点。等预算物理网格的 Top-5 在两种设置下均为 96.25%。
3. 峰宽失配后，完整谱上 MDN 加物理重排的 c MAE 从 0.00100 Å 升到 0.00313 Å，高于密集网格的 0.00151 Å。现有实验支持用物理重排改善可见谱拟合，同时也显示其参数精度依赖于正演假设。

范围仍限于模拟金红石单相、一个峰宽扰动和一档噪声。种子 43 的 MLP 达到 220 次迭代上限，结果表保留该次固定训练预算下的结果。扩展实验的计时受并发执行影响，运行成本以逐个运行的结果为准。

参考结构取自 Wyckoff 的 *Crystal Structures*（1963）及 Crystallography Open Database 9009083。仓库内的 CIF 保留原晶胞尺寸并显式展开六个原子位点。[COD 存档副本](https://github.com/cryos/avogadro/blob/master/crystals/oxides/TiO2-Rutile.cif) · [标准粉末谱](https://digital.library.unt.edu/ark:/67531/metadc13215/m1/89/) · [pymatgen 文档](https://pymatgen.org/pymatgen.analysis.diffraction.html)
